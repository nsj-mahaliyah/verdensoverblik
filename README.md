# Månedens Verdensoverblik

Månedlig storskærms-præsentation (6 områder: Lokalt, Danmark, Globalt, Mellemøsten, USA, Kina) til månedsmødet.

- `index.html` – den byggede side (genereres fra `src/index.template.html`)
- `data.js` – månedens indhold (sager, Top 5, pauseskærm, åbning/afslutning)
- `img/` – HD-billeder (2560×1600) · `img/sm/` – små versioner til fliser
- `src/` – skabelon, kort og byggenoter (se `src/LAESMIG.md`)

Opdateres én gang om måneden.
